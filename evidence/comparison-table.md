# Comparison table sources (issue #44)

Last verified 2026-11-16. Each cell of the table in "Tracing and observability platforms" comes from the source below. All pages returned HTTP 200 on 2026-11-16. Licences come from the GitHub API (`license.spdx_id`) and the repository's LICENSE file. Where a repo shows NOASSERTION, the README or LICENSE text was read. "Not documented" means the pages listed for that platform, plus its docs index (`llms.txt`) or README, did not say. It doesn't mean the feature is absent.

Column definitions:

- **Self-host:** the vendor documents running the backend on your own infrastructure.
- **OTLP ingest:** the backend documents an OTLP endpoint that accepts spans from any OpenTelemetry SDK.
- **OTel GenAI conventions:** the docs say the backend reads `gen_ai.*` attributes from incoming spans.
- **Evals built in:** the product runs evaluations or scorers itself.
